Package format and low-level package manager for Red Hat-family distros ([[Fedora]], RHEL, Rocky); day-to-day use dnf (resolves dependencies).

```bash
rpm -ivh package_to_install
```

```bash
rpm -e package_to_delete
```

```bash
# list files
rpm -ql package_name
```

```bash
# info
rpm -qi <pkg>
```
