Most if not all browser support [[HTML]], [[CSS]], [[Javascript]]

# Disable Web security
```shell
chrome --user-data-dir="<path/for/temporary/data>" --disable-web-security
edge --user-data-dir="<path/for/temporary/data>" --disable-web-security
```

# Override response
Most common browser might support feature to override [[REST API]] response as dummy alternative while waiting for backend.
