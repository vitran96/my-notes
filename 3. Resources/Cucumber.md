[[BDD|Behaviour-Driven Development]] test tool: runs plain-English [[Gherkin]] `.feature` specs, binding each step to code (step definitions).

- Java: `cucumber-java` + `cucumber-junit-platform-engine` (runs on [[JUnit]] 5 Platform); used for acceptance / [[Integration Test]]s.
- JS alternative with Playwright: [[playwright-bdd]].
