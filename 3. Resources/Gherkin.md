Plain-English test-spec language used by [[BDD]] tools ([[Cucumber]], [[playwright-bdd]]). Files: `*.feature`.

## Key points

- Keywords: `Feature`, `Scenario`, `Given` (context), `When` (action), `Then` (outcome), `And`/`But`, `Background`, `Scenario Outline` + `Examples`.
- Same shape as [[Arrange-Act-Assert]].
