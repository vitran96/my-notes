[[Linux Distro]] sponsored by Red Hat; upstream of [[RHEL]] (via CentOS Stream). See [[Rocky Linux]].
- Package manager [[dnf]] (dnf5 since Fedora 41); RPM-based ([[RPM]])
- Default [[File system]]: [[btrfs]] (since 33) · swap on [[ZRam]] (since 33)
- Editions/spins: Workstation ([[GNOME]]), KDE Plasma ([[KDE]])
- Disk encryption: [[LUKS disk encryption]]
